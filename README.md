# Namma Santhe Ledger

Namma Santhe Ledger is an Android finance and udhar management application developed using Kotlin and Jetpack Compose for small business vendors to digitally manage transactions, pending dues, and financial records.

---

## Features

- Income & Expense Tracking
- Udhar (Credit) Management
- Payment Tracking
- Dashboard Analytics
- Search Functionality
- WhatsApp Payment Reminder
- Permanent Local Storage using Room Database
- Modern UI with Jetpack Compose

---

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM Architecture
- Room Database
- Android Studio

---

## Problem Statement

Small vendors often maintain financial records manually, which leads to errors in tracking income, expenses, and pending payments.  
This application helps digitize and simplify vendor bookkeeping.
